# Contributing

Follow these three steps to propose a change.

## Branch

Create a topic branch off the main branch:

```
git checkout main
git pull
git checkout -b my-topic-branch
```

## Commit

Make small commits, each with a clear one-line message:

```
git add <changed files>
git commit -m "Describe the change in one line"
```

## Pull Request

Push the branch and open a pull request describing the change for review:

```
git push -u origin my-topic-branch
```

Then open a pull request against the main branch and explain what changed and why.
